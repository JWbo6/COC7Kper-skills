# CoC7车卡
仅在用户提供或任务指定时读取空白 XLSX、车卡教程、模板卡和已有角色资料；它们是参考，不是必需固定文件。每名角色使用稳定 ID，并与团、玩家、可见性关联。
收集或标注缺失：姓名、玩家、时代、职业、属性、技能、背景、装备、HP、SAN、MP、Luck、状态。派生值按用户指定的 CoC7 卡计算，无法确定就不猜。
基础规则：d100≤最终技能成功；困难/极难为一半/五分之一向下取整；01通常大成功，技能<50时96-00通常大失败，技能≥50通常仅00；奖励/惩罚骰改十位骰，不加减百分比。
修改 XLSX 时空白/模板只读，先确认单元格布局。`人物卡/模板卡/` 只用于读取版式、合并单元格、填写列、技能行和公式；角色内容必须从 `人物卡/空白卡/` 或干净模板开始，绝不复制参考角色的姓名、职业、属性、技能、背景、装备、隐藏页数据或任何个人资料。优先最小 XML 改动，保留公式、隐藏表、验证和保护，优先使用本机 Excel/LibreOffice 原生接口打开、填写和另存 XLSX；不得只依赖手工 XML 重打包。保存后必须再次用 Excel/LibreOffice 打开并读取姓名、职业、属性、技能和装备，确认没有“部分内容有问题”的修复提示；关键填写格必须真实显示，不能只在脚本中记录而导致 Excel 空白。同步 JSON/MD/表格，记录旧值、新值、原因、revision、event_id；不泄露秘密。
