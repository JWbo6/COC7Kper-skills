# CoC建团与模组访问
只读取用户提供或任务指定的模组源；支持 PDF、DOC、DOCX、MD、TXT。旧式 DOC 优先用可用解析器，失败则报告并请求文本，不猜内容。
1. 确认团名、规则、时代、地点、人数和源文件，缺项标待补。
2. 记录源文件大小、时间、哈希和解析状态；原文只读。路径必须在用户允许的目录内。
3. 新建团时，必须在团目录 `01-模组资料/原始模组/` 保存源文件副本；外部源保持原位，不移动、重命名或覆盖。复制后重新计算 SHA-256，副本缺失、目标冲突、路径越界或哈希不一致时停止，不把团标为已准备/活动。
4. 模组索引同时保留外部源路径和团内副本相对路径，并记录 `copy_status`；解析产物、主持资料和公开摘要写入团目录，玩家文件不得包含幕后内容。
5. 已存在的团目录按恢复/迁移模式处理：使用现有 `campaign_id`、revision、场次和角色记录，不重新建团，不覆盖非空文件；外部源可用时，缺少团内副本只作为待迁移项，除非用户明确要求迁移，不阻断继续主持。
6. 用户要求创建时才建立不冲突的团目录、团信息、模组索引及玩家/KP 分层摘要；不覆盖非空文件。
7. 只把模组明确写出的内容当事实，推测单独标注；报告路径、ID、解析失败、冲突和未完成项。
基础按 CoC7：d100≤技能成功，困难/极难为技能一半/五分之一向下取整；模组特殊规则优先并注明。
