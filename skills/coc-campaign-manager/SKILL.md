# CoC跑团总入口
先判断用户的唯一主动作，不读取固定说明、模板或历史记忆；当前团和角色资料只从用户指定位置恢复。
路由：初始化→coc-init-workspace；建团/模组→coc-campaign；车卡→coc-character；主持→coc-kp；掷骰→coc-dice；记录→coc-log；结团→coc-archive。
一次只执行一个写入流程；缺少团名、角色、模组或权限时先询问。写入前读取现状和版本号，冲突、重名、秘密泄露或失败时停止并报告，不宣称未完成。
建团子流程返回成功前，必须确认模组源已复制到目标团目录的 `01-模组资料/原始模组/`，且副本 SHA-256 与登记源一致；已有团则走恢复/迁移流程，不重新创建团目录或覆盖既有记录。
CoC7 基准：d100≤最终值成功，困难/极难为一半/五分之一向下取整；模组明确规则优先。
