# CoC工作区初始化
这是可选的通用检查，不读取任何固定说明、规则文档、模板或脚本。先确认用户指定的根目录，扫描目录、文件、大小、时间和哈希并报告现状。
只有用户明确要求创建时，才在根目录内建立最小目录/空文件；不移动、删除、重命名或覆盖既有资料，不改原始模组和空白角色卡。遇到同名、非空、权限、符号链接或路径越界就停止对应操作。
完成后重新扫描并核对已有资料哈希；任何失败、未创建或不确定都如实报告。
CoC7 内容只按基础规则处理：d100≤最终值成功，困难/极难为一半/五分之一向下取整；模组特殊规则需单独标注。
