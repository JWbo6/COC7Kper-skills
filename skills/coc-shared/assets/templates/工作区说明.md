# COC 工作区说明

本工作区用于 CoC 7 版跑团。生成 Skill 不移动、重命名、删除或覆盖既有资料。

## 标准结构

```text
COC/
├─ COC须知/（规则、车卡资料、KP资料、时代与设定）
├─ 模组/
│  ├─ 待整理/
│  ├─ 可开团/
│  └─ 已使用/
├─ 进行中的团/
│  └─ 年份-团名/
│     ├─ 00-团务/
│     ├─ 01-模组资料/（原始模组、主持人资料、模组索引）
│     ├─ 02-调查员/角色名/
│     ├─ 03-场次记录/
│     ├─ 04-调查状态/
│     └─ 05-素材/
└─ 结束的团/年份-团名/
```

## 记忆规则

每团核心记忆集中在 `00-团务/当前状态.md`、`玩家可知信息.md` 和 `03-场次记录/`。结构化状态放 JSON/JSONL，叙事和回顾放 Markdown，日志追加写入。KP 秘密只在主持人资料和内部状态中，绝不复制到玩家可知文件。新对话先读取团索引和当前状态。完整归档后才进入 `结束的团`，且先做冲突检查。
