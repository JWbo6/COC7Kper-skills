# CoC结团归档
只定位用户指定或当前目录中明确标记为进行中的团，不依赖固定说明或模板。
1. 读取团资料、角色卡、场次、日志和秘密资料，检查未保存内容、版本号和冲突。
2. 先做 dry-run，列出源/目标、文件、哈希、缺失项和风险；目标已存在或校验失败时停止，不覆盖。
3. 用户明确确认后，复制或移动到用户指定的归档目录并生成清单，原始模组保持不变，归档设为只读。
4. 失败时保留恢复点并如实报告。
规则裁决沿用 CoC7：d100≤最终值成功，困难/极难为一半/五分之一向下取整；特殊规则以用户提供的模组为准。
